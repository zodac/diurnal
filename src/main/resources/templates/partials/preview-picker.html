Extracted because the Theme / Calendar style / Font pickers were byte-identical but for their label, group, option list and selected value (UI_PATTERNS.md section 1: extract on the 2nd use). The radiogroup carries `hx-include` of ITSELF (`#{optionsId}`): htmx doesn't auto-serialize a bare
's descendant inputs the way a
does, so the group must include itself to send the checked radio's value. Params (all required): optionsId — the radiogroup's id AND its hx-include target (e.g. "theme-options") label — the section heading, reused as the radiogroup's aria-label (e.g. "Calendar style") group — the radio group name / submitted field (e.g. "theme" | "calendarView" | "font") endpoint — the hx-patch URL the group auto-saves to (204, no swap) options — the PreviewOption list to render as tiles (e.g. themeOptions) current — the user's currently-selected value (drives each tile's checked state) border — true to add the section divider below (between pickers), false on the last one !} {label}
