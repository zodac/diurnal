{! Numeric preference row (Settings → Preferences): a label, an optional help line, preset quick-pick pills (the primary one-click selection) and an optional −/+ fine-tune stepper, all writing the same number field, which auto-saves via its custom `save` event (fired by wireNumericPref in settings.js — the `save` event, not `change`, carries the PATCH so the field's own change handler can normalise + re-fire without recursing). The pill/stepper element ids derive from `id` ({id}Presets / {id}Minus / {id}Plus), matching the wireNumericPref(...) wiring. A row whose presets already cover the whole accepted range (Decimal places: 0/1/2) passes stepper=false: the pills ARE the complete choice, so a fine-tune stepper (and the free typing that comes with it) could only produce a value the server would reject. The field then still exists — hidden — because it is what carries the id, the form field name and the hx-patch. The two toggle rows in Settings (Statistics Summary, Character count) are laid out to match this one by hand rather than through this partial: their control is a single switch with no presets or stepper, so there is nothing to parameterise. Keep the two shapes in step. Params (all required): rowId — id of the row wrapper id — the number field's id AND form field name (the PATCH endpoint reads this @FormParam) label — the visible field label (also the field's aria-label) help — a help line under the label, or "" for none endpoint — the hx-patch URL min / max — the field's bounds, for the CALLER's own wireNumericPref(...) wiring (settings.js) - not rendered here (the field is `type="text"`; JS clamps, the server still validates authoritatively); unused when stepper=false value — the current value options — the preset values, rendered as pills in order stepper — true to render the −/+ fine-tune stepper, false for pills only minusLabel — aria-label for the − stepper button (unused when stepper=false) plusLabel — aria-label for the + stepper button (unused when stepper=false) border — true to add a bottom divider (between rows), false on the last row !} {! Two columns, not three stacked rows: the label and its help line on the left, the pills and the stepper beneath them on the right. The stepper therefore sits DIRECTLY under the pills that write the same field, instead of being pushed a line further down by a full-width help line between them. The left column is `min-w-0` so the help text wraps into as many lines as it needs; the right one is `shrink-0` so the controls are never squashed and the pills stay on one line. !}
