{! The notes data table (header + rows + pagination). Rendered on the full page (inside #note-list) and returned wholesale by GET /internal/notes/list for HTMX swaps. Params: page (PaginatedNotes), extraQuery (pre-encoded "&q=..." or ""). Every row is a link to the dashboard on that day (/?date=…) rather than an expander: the day is the unit the app is built around, and the dashboard already shows the note in full beside the actions logged against it, so following a result lands somewhere richer than expanding here. The snippet is a LIST of parts, not a marked-up string, so Qute still escapes every character of the note on the way out — {part.text} is escaped exactly like any other user value, and this template (not the server's string building) decides where the goes. Never render a note's text with {part.text.raw}. !}

Never js-digits alongside it: a note's own digits are the user's exact text and must never be transcoded (see NOTES.md's "must never be translated"). !} {/for} {#if page.items.isEmpty()} {/if}
