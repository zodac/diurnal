{! Randomise-colour button with the shared "Random colour" tooltip, wrapped in the `group relative` tooltip host. Asks the server (which knows every action's colour, not just the ones on this page) for a colour unlike the ones already in use and drops it into the nearest colour input - the one in the button's own
(the new-action card) or its own (a table row's edit state). Wired by data-random-colour in /js/actions.js; the value is only submitted with the surrounding form, so nothing is stored until that form is saved. Params: btnCls — the button's class list (required — sizing differs per context: the large round new-action control vs the compact .dt-icon-btn in a data-table row) iconCls — optional glyph class list; pass '' where a CSS rule sizes the glyph (`.dt-icon-btn svg`) wrapperCls — optional extra classes on the wrapper (e.g. 'shrink-0', or 'hidden' for an edit state) dtEdit — optional, default false: true to mark the wrapper [data-dt-edit] align — optional, default 'left': the tooltip's horizontal anchor !} {#let wrapperCls=wrapperCls.or('') iconCls=iconCls.or('') dtEdit=dtEdit.or(false) align=align.or('left')} {#include partials/tooltip text="Random colour" pos="bottom" align=align /} {/let}
