{! Debounced search filter for a paginated list: HTMX-swaps the filtered first page into the target as the user types. `data-search-source` points at the input itself so pagination links carrying the same marker keep the live search term in their requests (the delegated htmx:configRequest listener in app.js). Params: id — the input's id (also its data-search-source value) (required) url — the hx-get list URL, already reset to page 1 (e.g. "/internal/actions/list?page=1") (required) target — CSS selector receiving the swapped list (e.g. "#action-list") (required) placeholder — the input's placeholder text (optional, default "Search…") value — the initial value, for a page rendered with a search term already in the URL (the notes page, whose ?q= survives a reload/bookmark) (optional, default "") The two optional params are defaulted with `.or(...)` because Qute is strict: a bare {placeholder} on a caller that doesn't pass the key throws "Key not found" at render time. !} {#let placeholder=placeholder.or('Search…') value=value.or('')}
{/let}
